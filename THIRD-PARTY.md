# Vendored dependencies

Both are bundled into `index.html` so the app works offline and needs no CDN.

| Library | Version | Licence | Purpose |
|---|---|---|---|
| [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) | 5.2.2 | MIT | writes H.264 + AAC into an MP4 container |
| [webm-muxer](https://github.com/Vanilagy/webm-muxer) | 5.1.4 | MIT | writes VP9 + Opus into a WebM container |

Both © Vanilagy, MIT licensed. Rebuild with `node src/build.js`.
